# SDEV2301 Workbook Repository

⚠️ **Important:** This repository does **NOT contain assignment instructions or starter projects.**  
All assignment specifications and instructions are posted on **Brightspace**.

This repository is where you do your work that is not submitted for marks, such as:
- Examples done in class
- Code from slides
- Practice exercises

You may also create projects here to experiment with concepts covered in class.

By cloning this repository you will be able to push your work to GitHub, which:
- Shows your effort and practice
- Allows you to quickly share code you are working on
- Makes it easier to discuss issues with the instructor
